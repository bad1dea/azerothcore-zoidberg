# Commands

GM-gated when `IdleBot.AllowGMOnly = 1`.

## M1-M2 (implemented first)
- `.idlebot help`
- `.idlebot list`
- `.idlebot add <botName>`
- `.idlebot remove <botName>`
- `.idlebot status <botName>`
- `.idlebot pause <botName>`
- `.idlebot resume <botName>`
