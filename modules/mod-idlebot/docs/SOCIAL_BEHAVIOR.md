# Social behavior

`IdleBotSocial` is a separate concern so it can be disabled entirely. **Off by
default.** The owner controls how social bots are.

## Capabilities (when enabled)
- detect nearby real players
- detect shared quest objectives
- decide whether grouping is useful
- send an invite only if enabled
- accept invites only if enabled
- cooldowns on invites/whispers/emotes (idlebot_social_cooldowns)
- ignore players who declined
- leave group when objective complete or player too far
- optional simple chat lines (off by default)

## Rules
Never spam, grief, stalk, or harass. Only group within configured level
tolerance. Prefer shared objectives. Leave politely. Everything configurable and
easy to disable.
